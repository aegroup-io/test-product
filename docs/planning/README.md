# Planning Docs

`docs/planning/` is the working area for product-specific proposals, research, and backlog-shaping notes.

Put docs here when they answer questions like:

- What should we build next?
- What options are still being compared?
- What exploratory notes informed future implementation?

When a planning doc becomes durable guidance, move or distill it into:

- `docs/architecture/` for long-lived technical context
- `docs/harness/` for contributor workflow
